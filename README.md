# Volume Scroller
Volume Scroller allows you to quickly change the volume.

![This is an image](https://github.com/patrickiel/VolumeScroller/blob/main/icons/VolumeScroller_Logo_128.png) 

## Installation

**[Download VolumeScroller v2.3.9](https://github.com/jinhongel/VolumeScroller/releases/download/v2.3.9/VolumeScroller.exe)** — Windows x64 portable executable.

Run `VolumeScroller.exe` directly. The .NET desktop runtime, dependencies, and default configuration are bundled into the EXE; no installation or companion files are required. The app starts in the system tray without showing the settings window. Keep the EXE in a fixed location if you enable run on startup.

## Features
- Three operation modes:
    1. Taskbar - Works with both visible and hidden taskbar
    2. Taskbar Visible - Move the mouse over the visible taskbar and scroll up or down (requires taskbar to be visible)
    3. Screen Edges - Change volume by scrolling near the screen edges (configurable for all four corners)
- Run on startup (customizable)
- Custom volume increment
- Middle-click to mute/unmute within the configured taskbar or screen border region while keeping the volume level (optional); scrolling up unmutes and increases from that level
- Multi-monitor support
- Taskbar at different positions and sizes is supported
- Auto Dark Mode support (for tray icon)
